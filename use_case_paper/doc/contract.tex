\paragraph{Contract Definition.}
We define the assume-guarantee contract for the Fleet Coordinator as
$C = (A, G)$ where the assumption
$A \colon$ \emph{the Drone Agent transmits its anomaly report
(\texttt{snd\_report!}) within $300$\,ms of anomaly detection}, and
the guarantee
$G \colon$ \emph{the Fleet Coordinator issues a treatment command
(\texttt{snd\_treatment!}) within $500$\,ms of anomaly detection}.

\paragraph{Contract Satisfaction under RTWBS.}
In the deployed system $\mathit{DA}_{\mathrm{abs}}$, the waypoint
message is processed in a committed location (zero delay), so the
drone's anomaly report is sent at
$t_{\mathrm{report}}^{\mathrm{abs}} = t_{\mathrm{detect}} + t_{\mathrm{proc}}$,
where $t_{\mathrm{proc}} \leq 50$\,ms.  Since
$t_{\mathrm{report}}^{\mathrm{abs}} \leq 50\,\text{ms} \ll 300$\,ms, assumption $A$
holds and the FC meets guarantee $G$ with margin.
%
In the updated system $\mathit{DA}_{\mathrm{ref}}$, duty-cycled
processing introduces an additional input-side delay
$\delta_{\mathrm{duty}} \leq 40$\,ms, yielding
$t_{\mathrm{report}}^{\mathrm{ref}} \leq 50 + 40 = 90$\,ms $< 300$\,ms,
so assumption $A$ is still satisfied.
%
Crucially, the \emph{output} action \texttt{snd\_report!}\ is never
delayed beyond the abstract system's deadline: the duty-cycle delay
only shifts the \emph{input consumption} timestamp of
\texttt{rcv\_waypoint?}, which is permitted by RTWBS Condition~4
(relaxed input reception).  The output deadline (Condition~3, strict
output preservation) is preserved because the treatment command
remains within $500$\,ms in both systems.
%
By Theorem~3, since $\mathit{DA}_{\mathrm{ref}} \preceq_{\mathrm{RWTBS}} \mathit{DA}_{\mathrm{abs}}$
and $G$ is an upper-bound timing constraint on a \emph{sent} event,
any contract $C = (A, G)$ satisfied by $\mathit{DA}_{\mathrm{abs}}$ is
also satisfied by $\mathit{DA}_{\mathrm{ref}}$.
\qed
